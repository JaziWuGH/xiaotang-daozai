# B：实时绑定、动画与交互

分支 `feat/plugin-canvas-live`，从 `feat/plugin-canvas` 开出。共同规则见 [README](README.md)。

A 定好了数据结构。本任务让画布动起来、能点：

- 绑定求值；
- 数字翻动；
- 过渡和循环动画；
- 点按与悬停；
- 滚动区。

## 先读

- A 的说明和代码。
- `src/plugin_status_realtime.rs`：现有 counter、clock、countdown 的计算方式和重绘安排，可以复用。
- `spike/plugin_interactions.rs`：按钮点击、调用队列、旧点击作废的机制。
- `src/main.rs` 里的 `page_animating`、`interactive_transition`：兼容渲染下动画帧的交付方式。

## 绑定

画布的 `binds` 定义名字和来源，节点里引用这些名字。

```json
"binds": {
  "money": {"counter": {"start_value": 0, "per_second": 0.0167, "start_at": 1795400000, "decimals": 2}},
  "left":  {"countdown": {"target_at": 1795431600, "format": "HH:mm:ss"}},
  "work":  {"progress": [1795392000, 1795424400]},
  "ny_h":  {"clock_angle": {"zone": "America/New_York", "hand": "hour"}},
  "now":   {"now": "HH:mm"}
}
```

| 来源 | 结果 |
| --- | --- |
| `counter` | 格式化后的数字文字，同时可作数值使用 |
| `countdown` | 格式化文字，`format` 与现有倒计时一致；同时可作剩余秒数使用 |
| `progress` | 0 到 1 的数值：现在处在 `[开始, 结束]` 之间的位置，越界时取 0 或 1 |
| `clock_angle` | 指定时区现在的时针或分针角度（度） |
| `now` | 格式化的现在时间，可加 `zone` |
| `daylight` | 指定时区现在是否在 `[开始时, 结束时]` 之内，结果为 0 或 1，用于按日夜换色 |

用法：

- 文字里写 `{money}` 直接替换。
- 数值字段写 `{"bind":"work","map":[0,210]}`，把 0 到 1 线性映射到区间。可用于弧的 `sweep`、矩形宽度、坐标、旋转角度、透明度。
- 颜色字段写 `{"bind":"day","pick":["#2E64B5","#FFC43D"]}`，按 0 或 1 取色。

重绘安排：

- 按所有绑定里最近的变化点安排下一次重绘：显示到秒的每秒一次，显示到分钟的每分钟一次，`progress` 按像素精度推算。
- 页面不可见、岛收起或插件停用时停止计算。

## 动画

- **数字翻动**：文字节点加 `"roll": true` 后，数字变化时只有变了的那几位向上翻。翻动时长 220 毫秒。
- **过渡**：节点加 `"animate": {"ms": 300, "ease": "spring"}`。两次输出之间同一 `id` 的节点，位置、尺寸、角度、透明度、颜色平滑过渡；新增节点淡入，消失的节点淡出。`ms` 范围 120 到 1200。
- **循环**：节点加 `"loop": {"kind": "pulse" | "flow" | "bob" | "spin", "period_ms": 1600}`。
  - 同时最多 8 个节点循环，周期至少 800 毫秒。
  - 循环帧率最高每秒 30 帧，只在页面展开且可见时运行。
  - 用于工资经验条的条纹流动、小人上下浮动、午休打呼。
- **一次性效果**：`"burst": "confetti"`，在节点位置撒一次彩纸，用于通关。同一 `id` 只播放一次。
- 有动画进行时，这些帧在兼容渲染下要走交互帧，帧率要达到每秒 60 帧，参考 `page_animating`。动画结束后回到静止，不产生多余帧。

## 岛仔节点

画布可以放一个由宿主绘制的岛仔，插件不用自己画脸。

```json
{"pet": {"at": [226, 8], "size": 28, "mood": "expressions", "motion": "run", "id": "pet"}}
```

- 绘制复用 `src/pet.rs` 和 `src/pet_expressions.rs`：同样的造型、表情图集和配色，并跟随用户安装的表情包。
- `mood` 可选值：
  - `expressions`：每 6 到 10 秒随机换一个现有表情，共 12 种，即 wink、smug、blush、delighted、side-glance、praised、heart、giggle、shy-peek、scan、peek、search；
  - `sleeping`：睡觉；
  - `happy`：开心；
  - `praised`：被夸；
  - 具体某个表情名。
- `motion` 可选值：
  - `run`：原地跑跳循环，像游戏加载页的小人。一个循环约 700 毫秒，依次是蓄力压扁、起跳拉长、空中、落地扬尘（地面两三个小灰点）。
  - `bob`：轻轻上下浮动。
  - `none`：不动。
- `at` 可以用绑定，例如 `{"bind":"work","map":[0,360]}`，让岛仔跟着进度条走。
- 动作和表情都算循环动画，计入 B 的循环上限，只在展开且可见时播放，帧率规则与其他循环相同。
- 每个画布最多 1 个岛仔节点；常驻小画布不支持。

## 交互

- 节点加 `"hit": {"action": "id"}`，也可以写 `{"open": "https://…"}` 或 `{"copy": "文字"}`。规则与现有按钮一致：
  - `open` 只能打开 `network.hosts` 里的地址；
  - `copy` 最多 2000 字；
  - 旧点击在输出更新后作废。
- 点击区域取节点的外框，分组取整组外框。每个画布最多 64 个点击区域。
- 悬停：`"hover": {"opacity": 1, "lift": 2, "fill": "#…"}`。宿主在悬停时套用这些样式，用 `animate` 时长过渡。
- 滚动区：分组加 `"scroll": {"axis": "y", "content": 420}`，内容超出时可以用滚轮在区域内滚动。
  - 滚动区里的滚轮不能触发翻页。参考 `set_page_scroll_area` 的现有做法。
  - 滚动位置在同一插件的多次刷新之间保留。
- 鼠标在画布上移动时，宿主把相对坐标传给脚本是**不做**的。图表悬停读数用下面的「悬停提示」实现。
- 悬停提示：折线节点加 `"tips": [{"x": 140, "label": "12:40", "value": "4,106.2"}, …]`。鼠标靠近某个 x 时，宿主画十字线和提示框，样式统一。

## 验收标准

- 单元测试覆盖：
  - 每种绑定在边界前后的取值；
  - 跨午夜和夏令时切换的 `clock_angle`；
  - 数值映射与取色；
  - 动画数量和周期上限；
  - 点击区域上限；
  - 旧点击作废；
  - 滚动区与翻页不冲突。
- 演示插件扩展为「会动」的版本：一个跳动金额、一个随时间走的进度弧、一个指针表盘、一个可点按的切换和一个滚动列表。
- 在 60 Hz 屏幕上使用 release 测试版进行 DX12 兼容渲染验收，开启 `DAOZAI_RENDERER=wgpu` 和 `DAOZAI_FRAME_TRACE=1`。在隔离配置的诊断目录确认兼容后端及分层显示已生效。
- 展开实时画布，累计采集至少 45 个数字翻动期间相邻交互帧的间隔。展开静止画布，待翻页结束后采集 30 秒。用 `python spike/check-canvas-frames.py <动画日志> <静止日志>` 校验。相邻交互帧间隔约 17 毫秒，静止时无动画帧及高频交互读回。进入交互帧的更新入口差值包含普通帧的节流等待。静止采样期间如出现连续日志轮转，保留轮转前后的日志用于核对。
