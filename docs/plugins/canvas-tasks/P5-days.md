# P5：日子（倒计时 + 节假日合并）

插件仓分支 `feat/official-days`，插件 ID `daozai.days`。逻辑层现在就能开工，画面层依赖 A、B、C；投稿依赖 P0。设计稿：「理想版 · 日子」。共同规则见 [README](README.md)。

参考 `spike/examples/countdown` 和 `spike/examples/holidays`：节假日数据格式和日历标注的写法沿用它们。

## 清单

- 归属 `owner: "tasks"`。
- 能力：`card`、`calendar.marker`、`status.page`、`status.canvas`、`timer`、`settings`、`action`、`notice`、`island.pinned`。
- 数据文件：`data: ["holidays-2026.json", "holidays-2027.json"]`。随包带当年和次年的数据；次年数据未公布时文件里标 `pending: true`。

## 设置

`days`：`list`，最多 20 项。每项包含：

| 子项 | 类型 | 说明 |
| --- | --- | --- |
| `name` | text | 最多 12 字 |
| `date` | date | 日期 |
| `kind` | choice | 倒数、纪念日（正数）、生日 |
| `yearly` | switch | 每年重复 |
| `icon` | icon（C 新增） | 默认按类型：倒数是旗子，纪念日是爱心，生日是蛋糕 |
| `color` | color（C 新增） | 默认按类型 |
| `pinned_text` | text | 这个日子的常驻文字模板，最多 24 字 |

其他设置：

- `pinned_day`：choice，「最近的那一天」或列表里的某一项；
- `show_holidays`：switch，默认开。

## 界面

整页画布，高 200。

**左侧手撕日历**，宽 150：

- 米白纸、红色页眉写「距 名称」和「放假 N 天」，页眉上有两个装订孔，后面露出两页纸边。
- 中间是大号红字天数，下方写「天」。纪念日写「已 N 天」。
- 底部写日期和星期。
- 显示的是「最近的那一天」，节假日和自己的日子一起比较。
- 每天 0 点刷新时，用 `animate` 让旧页向右下飞出，新页露出。

**右侧**：

- 顶部一行：筛选钮「全部 / 节假日 N / 我的 N」（画布点按区），右侧显示当周的调休提醒。
- 下面是车票列表，放在滚动区里：
  - 每个日子一张，高 32，按日期排序。
  - 左段写名称和「日期 · 放假 N 天 / 每年」，右段隔一条虚线写天数。
  - 两侧有半圆缺口。
  - 车票颜色：法定假期按节日取色，自己的日子用设置里的 `color`。
- 当天：日历页显示「今天」，车票这一张加高亮边框。

## 待办卡和日历标注

保留首版的写法：

- 待办卡写最近一天和当周调休；
- 日历当天下方标注节日名，放假标「休」，调休上班标「班」。

## 常驻

- 用常驻小画布，显示 `pinned_day` 选中的日子：该日子的图标、颜色和常驻文字。
- 模板支持 `{名称}`、`{天数}`、`{日期}`、`{星期}`。
- 未填模板时用默认写法：
  - 倒数：「名称 还有 N 天」；
  - 纪念日：「名称 N 天」；
  - 生日：「名称 生日还有 N 天」。
- 当天改用「今天是 名称」。

## 提醒

- 纪念日满整百、整千天当天发一次 `notice`。
- 生日当天发一次 `notice`。
