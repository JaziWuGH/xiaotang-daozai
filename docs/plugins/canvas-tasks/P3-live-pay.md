# P3：实时工资

插件仓分支 `feat/official-live-pay`，插件 ID `daozai.live-pay`。逻辑层现在就能开工，画面层依赖 A、B、C；投稿依赖 P0。设计稿：「理想版 · 实时工资」。共同规则见 [README](README.md)。

参考 `spike/examples/live-pay` 的计算部分。

## 设置

| 键 | 类型 | 默认 |
| --- | --- | --- |
| `salary` | number，元/月 | 无，未填时页面提示去设置 |
| `start`、`end` | time | 09:00、18:00 |
| `breaks` | list，最多 4 段 | 一段「12:00–13:30，不计薪」 |
| `days` | weekdays | 一至五 |
| `pinned_show` | choice | 金额（默认）、下班倒计时、两者轮换 |

`breaks` 每段有三个子项：

- `from`：time，开始时间；
- `to`：time，结束时间；
- `paid`：switch，这段是否计薪，默认关。

规则：

- 用户可以删掉全部段，表示无午休。
- 各段必须在上下班之间且不重叠，设置页对不合规的段给出提示。

日薪 = 月薪 ÷ 当月工作日数；每秒 = 日薪 ÷ 当天计薪秒数（不计薪的休息段不算在内）。

## 界面

整页画布，高 200。

- **标题下一行**：「今天已赚」加每秒增量。
- **计价器**：
  - 「¥」加每位一格的数字。整数位数按金额变化，小数两位。
  - 用 `counter` 绑定，开 `roll`，最后一位用强调色。
- **游戏经验条**，高 16：
  - 左边是「LV.N」，N 为当前第几个工作小时。
  - 进度用 `progress` 绑定，从上班到下班。
  - 填充带斜条纹，开 `loop: flow`，有外发光。
  - 每小时一条分隔线。
  - 每个休息段用橙色斜纹标出。不画饭碗等检查点图标。
  - 末端放终点旗。
  - 岛仔沿进度移动：用 B 的 `pet` 节点，`at` 绑定上下班进度。
    - 工作时：`mood: "expressions"`，`motion: "run"`。岛仔在进度头原地跑跳，表情随机轮换。
    - 不要自己画岛仔的脸，由宿主绘制，这样会跟随用户的表情包。
- **底部一行**：
  - 左边「第 N 小时 · 本小时已赚 ¥x」。
  - 右边绿色胶囊「距离通关 HH:mm:ss」，用 `countdown` 绑定。

## 状态切换

- 用 `next_refresh_at` 在上班、每个休息段的开始和结束、下班这几个时刻刷新。
- 休息段内：
  - 经验条换成橙色回血条。
  - 岛仔切到 `mood: "sleeping"`、`motion: "none"`，旁边用文字节点冒「Zz」（`loop: pulse`）。
  - 不计薪的段计价器停住；计薪的段照常跳动。
- 下班后：
  - 显示「通关！今天到手 ¥x」。
  - 岛仔切到 `mood: "praised"`、`motion: "bob"`，旁边插一面旗；撒一次彩纸（`burst`），同一天只播放一次。
- 休息日：显示「今天不打怪」和距离下个工作日上班的倒计时。
- 下班时发一次 `notice`：「下班啦」。正文不写金额。

## 常驻

- 常驻小画布按 `pinned_show` 显示：
  - 金额：金币图标加跳动金额，带 `roll`；
  - 下班倒计时：旗子图标加倒计时；
  - 两者轮换：每 8 秒切换一次，随常驻轮播节奏走。
- 插件本身不做打码。

## 验收

- 截图：
  - 上班中；
  - 休息段（计薪和不计薪各一张）；
  - 无午休；
  - 通关；
  - 休息日；
  - 常驻的三种显示。
- 单元测试：
  - 当月工作日数；
  - 多个休息段、无休息段、计薪段对每秒金额的影响；
  - 休息段越界或重叠的校验；
  - 各状态切换时刻；
  - 跨午夜的上下班设置（如 22:00–06:00）。
- 用 `DAOZAI_FRAME_TRACE=1` 确认：只有经验条在流动时，帧间隔正常，岛收起后不再出动画帧。
