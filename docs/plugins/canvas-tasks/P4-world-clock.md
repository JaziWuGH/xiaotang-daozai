# P4：世界时钟

插件仓分支 `feat/official-world-clock`，插件 ID `daozai.world-clock`。逻辑层现在就能开工，画面层依赖 A、B、C；投稿依赖 P0。设计稿：「理想版 · 世界时钟」。共同规则见 [README](README.md)。

## 设置

- `cities`：`list`，最多 10 项。每项包含：
  - `name`：text，显示名，默认取城市表里的中文名；
  - `zone`：C 新增的 `timezone` 类型。
- `pinned_city`：choice，从已添加的城市里选一个常驻。
- 清单声明 `timezones: true`。

## 界面

整页画布，高度随城市数变化：

- 1–5 个城市：一行表盘，表盘直径放大到 64；
- 6–10 个城市：两行，每行 5 个，表盘直径 46；
- 页面高度范围 236 到 344。

**表盘**：

- 只画 12、3、6、9 四个刻度。时针粗、分针细，端头为圆角。
- 指针角度用 `clock_angle` 绑定，按分钟走。
- 当地 6–18 点：米白盘面 `#F4F1EA`，深色指针，中心点橙色。
- 其余时间：深蓝盘面 `#101626`，浅色指针，中心点蓝色。
- 换色用 `daylight` 绑定。
- 表盘下方依次是：城市名、数字时间（`now` 绑定，带 `zone`）、「昨天 / 今天 / 明天 · ±Nh」。
  - 半小时时区写成「+5.5h」。

**24 小时色条**：

- 每个城市一行，高 5，左侧是城市名。
- 横轴是本机时区的 0–24 点。
- 每行把该城市当地 9–18 点对应的区段画成黄色 `#FFC43D`，其余为蓝色 `#2E64B5`。
- 一条白色竖线表示现在，用 `progress` 绑定当天 0 点到 24 点。
- 底部写 0、6、12、18、24 刻度和「本机时区」名称。

**点按**：点任一表盘，`action` 把它设为常驻城市。

## 常驻

常驻小画布：迷你表盘（随日夜换色）加城市名和数字时间。

## 验收

- 截图：3 个城市、10 个城市、跨日期变更线的城市（如奥克兰）、正在切换夏令时的城市。
- 单元测试：
  - 色条区段在跨午夜时拆成两段；
  - 半小时和 45 分钟时区（加德满都）；
  - 「昨天 / 明天」判断；
  - 城市数量与页面高度的对应。
