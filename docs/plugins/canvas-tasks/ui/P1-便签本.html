设计说明
  • 不设条数上限，只受插件私有存储 256 KiB 限制（几千条短便签）；存储快满时在详情里提示导出。
  • 左边那摞纸是「当前这张」：完整显示正文，底部三个操作：复制、完成、常驻到岛上。
  • 右边列表点哪条，哪条就飞到纸堆最上面；颜色条代表来源（手写黄、专注红、粘贴蓝）。
  • 置顶不限条数，置顶组排在最前，组内可拖动排序。
  • 搜索在本地即时过滤，不联网。
  • 专注结束自动记一条红色便签，写上时长。
实现方式
两色标题、日期胶囊、左右箭头宿主统一

输入框、搜索框fields
分组列表、颜色条、置顶、可滚动自绘画布 · 滚动区
点按切换当前便签、完成、撤销action
