设计说明
  • 手撕日历：米白纸、红色页眉、两个装订孔，下面压着几页纸的边。最近的那一天印成大红数字。
  • 每过一天，最上面一页被撕掉（向右下飞出），下一页露出来。
  • 车票：每个日子一张，颜色按类型（生日橙、法定假期红、纪念日紫），右侧虚线撕口写天数；纪念日写「N 天了」。
  • 车票列出接下来的全部节假日和自己的日子，可按「全部 / 节假日 / 我的」筛选，上下滚动。
  • 调休上班只在当周出现，放在筛选条右侧。
  • 每个日子在设置里可填：名称、日期、类型（倒数 / 纪念日正数 / 生日）、每年重复、图标（爱心、蛋糕、戒指、飞机、星星、礼物…）、颜色、常驻文字。
  • 常驻哪个日子由用户选（设置或在车票上点「常驻」）；常驻条用这个日子自己的图标和文字模板，模板支持 {名称} {天数} {日期} {星期}。
  • 当天：日历页撕掉后显示「今天」，常驻文字换成「今天是{名称}」。
