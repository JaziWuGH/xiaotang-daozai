设计说明
  • 价格上方的切换钮决定主显示单位，选择会记住；另一种单位以「折合」放在下面。
  • 切换后走势图整条换算重画，坐标、悬停读数、提醒线标签同步换单位。
  • 两种单位都直接问 xaus.com：美元请求 currency=USD&unit=ounce，人民币请求 currency=CNY&unit=gram，换算由 xaus 完成，不需要第二个汇率来源。xaus 返回 fx_stale（汇率过期）时，人民币视图标「汇率待更新」。
  • 涨跌色块默认红涨绿跌，可在设置里改。
  • 页脚写数据来源和更新时间，不出现「建议」「看涨」等字样。
