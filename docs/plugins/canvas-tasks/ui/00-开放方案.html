开放方案：标准组件 + 自绘画布

不再给每种设计补一个组件。开放一个「自绘画布」：插件描述要画的图形，岛仔负责画、缩放、主题、帧率和安全。五个官方插件都用它来做，顺便当样例。

三层结构
标准组件（已有，保留）状态行、指标、列表、折线、计数、时钟、倒计时、按钮、输入框。零设计也好看，适合工具型插件。
自绘画布（新增）矩形、圆角、圆、弧、线、路径、文字、包内图片、分组、渐变、阴影、发光、裁剪。可以和标准组件混排，也可以整页都是画布。
宿主实时值（两边共用）现在时间、计数器、倒计时、城市时钟、某段时间的进度。画布里写「绑定」，岛仔每帧算，脚本不用每秒跑。
为什么这样比逐个补组件好
  • 做一次渲染器，所有插件都受益；新设计不需要我们再写代码。
  • 作者的上限由他的审美决定，不由我们的组件清单决定。
  • 仍然是数据不是代码：不能联网取图、不能读文件，岛仔能检查和限流。
插件返回什么（以「日子」的日历页为例）
// refresh() 返回，和 status 同级
canvas: { height: 196, nodes: [
  { rect: [0, 0, 150, 196], r: 10, fill: "#FBF8F1", shadow: "lg" },
  { rect: [0, 0, 150, 30], r: [10,10,0,0], fill: "$accent" },
  { text: "距 元旦", at: [10, 19], size: 11, weight: 700, color: "#fff" },
  { text: "{days}", at: [75, 100], size: 62, weight: 900,
    align: "center", color: "$accent",
    bind: { days: { countdown: 0, unit: "day" } } },
  { arc: { c: [75, 100], r: 64, sweep: { progress: ["2026-10-08", "2027-01-01"] } },
    stroke: "$accent", width: 4, glow: true },
  { hit: [0, 0, 150, 196], action: "open-calendar", hover: { lift: 2 } }
]}
// 常驻条：同样的格式，限高 22、宽 156
pinned: { canvas: { nodes: [ … ] } }
护栏
  • 字体默认用岛仔自带的；用户装了「字体包」插件后，画布可按名字引用（缺字时回退到岛仔字体）。颜色可写 $accent、$text、$muted、$card，换皮肤自动跟随。
  • 每页最多 1500 个图元，图片只能来自插件包（合计 512 KiB）。
  • 动画只能声明（数值变化时过渡、有限次的循环），不能让脚本每帧跑。
  • 绘制超时自动降级为静态画面，并在开发调试里提示作者。
  • 隐私交给用户：插件不强制打码，用户可用岛仔已有的「截图和录屏中隐藏」等设置。

已有的照常保留
  • 状态页标准组件、设置类型、联网取数、提醒、事件、存储都不变。
  • 老插件不用改；想变好看的插件只需多返回一个 canvas。
还需要补的小项
  • 设置类型 timezone：中文城市搜索并带出时区（世界时钟）。
  • 多行文本输入（便签）。
  • 插件私有存储导出（便签不限条数时用）。
  • list 设置的子项支持 icon、color（日子选图标和颜色）。
  • 字体包：新的外观资源包类型 appearance.font。
