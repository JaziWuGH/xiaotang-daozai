设计说明
  • 主角是计价器式数字：每位一格，变化时那一格向上翻，最后一位用绿色。
  • 下面是一条游戏经验条：一天就是一关，每小时一格，左边写「LV.5」表示第 5 小时；条纹会缓慢流动。
  • 休息时段在设置里自己填：可以加多段（午休、下午茶），也可以一段都不填（无午休）。经验条上用橙色斜纹标出。
  • 进入休息时段：进度条变成橙色回血条，岛仔闭眼冒 Zz，计价器暂停（每段可单独设成「计薪」）；结束自动醒来。
  • 常驻条显示内容可选：金额、下班倒计时、两者轮换。隐私由用户自己决定，插件不强制打码。
岛仔的动作（展开时在进度头原地循环）
蓄力 起跳 · 眯眼 空中 · 爱心 落地 · 扬尘 斜眼
  • 动作：原地「蓄力 → 起跳 → 空中 → 落地扬尘」循环，一次约 0.7 秒，像游戏加载页的小人。只在展开且可见时播放，收起即停。
  • 表情：工作时每 6–10 秒随机换一个现有表情（wink、得意、害羞、爱心、斜眼…），跟随用户装的表情包。
  • 休息时段改为睡觉姿态，通关时用「被夸」表情举旗。
  • 岛仔由岛仔自己画（画布里的 pet 节点），插件只给位置、动作和状态，不画脸。
