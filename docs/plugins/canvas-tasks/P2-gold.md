# P2：现货金价

插件仓分支 `feat/official-gold`，插件 ID `daozai.gold`。逻辑层现在就能开工，画面层依赖 A、B、C；投稿依赖 P0。设计稿：「理想版 · 现货金价」。共同规则见 [README](README.md)。

参考 `spike/examples/gold-price`，它已经跑通 xaus.com 的人民币每克报价。

## 数据

- `network.hosts: ["xaus.com"]`，两个来源：
  - `usd`：`https://xaus.com/api/v1/spot?currency=USD&unit=ounce&compact=1`
  - `cny`：`https://xaus.com/api/v1/spot?currency=CNY&unit=gram&compact=1`
- 换算由 xaus 完成，不需要另外的汇率来源。
  - 返回 `fx_stale: true` 时，人民币视图在价格下标「汇率待更新」。
  - 美元视图不受影响。
- 刷新：`minRefreshSeconds: 60`，默认 300，用户可调。
- 存储：两种单位各保留最近 48 个价格点，带时间戳。
  - 「1周」「1月」区间按小时、按天降采样后另存，各 48 个点。
- `attribution: {label: "xaus.com"}`。

## 设置

| 键 | 类型 | 说明 |
| --- | --- | --- |
| `unit` | choice | `usd`（美元/盎司）、`cny`（人民币/克），默认 `cny`，也可在页面上切换 |
| `range` | choice | 1日、1周、1月 |
| `alert_usd` | number | 美元提醒价，0 表示不提醒 |
| `alert_cny` | number | 人民币提醒价，0 表示不提醒 |
| `up_color` | choice | 红涨绿跌（默认）、绿涨红跌 |

## 界面

整页画布，高 196。

- **左栏**（宽 138）：
  - 单位切换钮（画布点按区，触发 `action` 修改 `unit`）；
  - 主价格，30 号字、800 字重；
  - 涨跌色块：三角加涨跌额和百分比；
  - 三行小字：折合另一单位、今日高、今日低。
- **右栏**：
  - 区间切换钮；
  - 面积图：带纵轴价格、横轴时间、末点发光、提醒价虚线和标签；
  - 鼠标悬停显示十字线和读数（B 的 `tips`）。
- **页脚**：数据来源、页码点（宿主）、更新时间。
- 切换单位或区间时，整张图用 `animate` 平滑过渡。

## 其他行为

- 提醒：
  - 价格从提醒价一侧跨到另一侧时，发一次 `notice`，例如「金价涨破 ¥950」。
  - `notice.id` 带单位、价位和方向，同方向不重复。
- 常驻：
  - 常驻小画布显示「金」字加当前单位的价格加 30 宽的迷你走势。
  - 走势线颜色按涨跌取。
- 取数失败：
  - 撤下旧读数，显示「数据源暂不可用」，常驻返回 null。
  - 退避由宿主负责。
- 全文不出现「建议」「看涨」「看跌」等字样。

## 验收

- 截图：美元视图、人民币视图、悬停读数、汇率待更新、取数失败。
- 用本地假数据跑单元测试：
  - 单位切换；
  - 区间降采样；
  - 提醒跨线去重；
  - `fx_stale`；
  - 涨跌配色设置。
