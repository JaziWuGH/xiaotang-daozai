# P1：便签本

插件仓分支 `feat/official-notes`，插件 ID `daozai.notes`。逻辑层现在就能开工，画面层依赖 A、B、C；投稿依赖 P0。设计稿：「理想版 · 便签本」。共同规则见 [README](README.md)。

## 插件

- 能力：`status.page`、`status.canvas`、`action`、`event`、`notice`、`storage`、`island.pinned`、`settings`。
- 设置：
  - `pin_mode`（choice）：指定一张、最新一张、置顶轮播；
  - `pin_id`（隐藏的 text，记录被指定的那张）。
- 存储：`{notes:[{id,text,color,source,pinned,done_at,created_at}], current, next_id}`，不设条数上限。

## 界面

整页画布，高 230。

- **左侧纸堆**，宽 168：
  - 最上面一张完整显示当前便签：第一行粗体，其余正文。
  - 后面露出两张纸的边。
  - 底部三个按钮：复制、完成、常驻。
- **纸堆下方**是输入框和「＋」，用 `fields`（`multiline`）加 `actions`。也可以用画布的点按区配合标准输入框，以设计稿为准。
- **右侧**：
  - 搜索框（`fields`）。
  - 搜索框下面是分组列表：置顶、今天、昨天、更早。
  - 每行有颜色条、标题、时间。常驻中的那一行末尾加一个蓝色小条。
  - 列表放在滚动区里。
- 点列表某一行，`action` 把它设为 `current`；纸堆用 `animate` 让新纸片从右侧滑到最上面。
- 完成：
  - 这一行划线后淡出，提示条显示「撤销」3 秒。
  - 3 秒后移入「已完成」，30 天后清理。
- 置顶不限条数，置顶组内按置顶时间排序。
- 颜色按来源取：手写黄 `#FFE58A`、专注红 `#FF8A7A`、粘贴蓝 `#8FD3F5`。

## 其他行为

- `focus.finished` 事件：自动新建一条红色便签「完成一次专注 · N 分钟」。
- 常驻：
  - 用常驻小画布：纸片色块加一行文字，文字太长时滚动一遍。
  - 显示哪一张按 `pin_mode` 决定。
  - 没有可显示的便签时返回 `pinned: null`。
- 搜索：脚本按输入过滤，空搜索显示全部。
- 存储接近 256 KiB 时，状态行提示「便签较多，可在详情里导出备份」。

## 验收

- 和设计稿同尺寸的截图：正常状态、完成后撤销提示、空状态。
- 单元测试（JS 部分用插件仓的测试脚本，或在岛仔里用 `sdk_spike` 跑脚本）：
  - 添加、完成、撤销、置顶、搜索、常驻三种模式；
  - 专注事件。
- 1000 条便签时，刷新仍在 30 毫秒限制内，输出不超过 64 KiB。超出时只把可见部分放进画布。
