# C：常驻小画布、字体包与设置补项

分支 `feat/plugin-canvas-extras`，从 `feat/plugin-canvas` 开出，可以和 B 同时做。共同规则见 [README](README.md)。

## 先读

- `spike/pinned.rs`：常驻位的数据、轮播和让位规则。
- `spike/appearance_assets.rs`：皮肤、图标、表情资源包的格式和安装。
- `spike/script_settings.rs`：设置类型的解析、保存和绘制。
- 插件详情和「已安装」列表的相关代码，`spike/local_ui.rs`。

## 1. 常驻小画布

- `pinned` 新增 `canvas` 字段，与现有的 `text`、`value`、`icon` 二选一。
- 尺寸：高 22，宽最多 156，作者用 `width` 声明实际宽度。
- 节点最多 60 个，支持 B 的绑定和数字翻动，不支持点按区域（点常驻条仍是打开插件页）。
- 现有的轮播、让位、开关规则不变。
- 验收样例：用迷你进度环 + 跳动金额，和色块 + 一行滚动文字各做一个。

## 2. 字体包

- 新的外观资源包能力 `appearance.font`，运行环境 assets，归属 appearance，可以和其他外观包同时启用。
- 入口 JSON 写法：`{"fonts":[{"name":"站酷快乐体","file":"zcool-kuaile.ttf"}]}`，最多 4 个字体文件。
- 字体文件格式为 TTF 或 OTF，单个最多 8 MiB，整包最多 16 MiB。这些资源包的大小上限需要单独放宽。
- 包里必须带 `LICENSE` 或 `OFL.txt`，安装时检查文件存在。
- 启用后，字体以 `plugin:<名字>` 注册进 egui 字体表。画布文字节点写 `"font":"站酷快乐体"` 即可使用，未安装或缺字时回退到岛仔字体。
- 停用或卸载字体包后，引用它的画布回退到默认字体，不报错。
- 本任务不做「全局替换岛仔字体」，只给画布使用。

## 3. 设置补项

- **时区类型 `timezone`**：设置页显示一个可搜索的选择框。
  - 输入中文城市名或国家名，例如「纽约」「美国」，列出匹配的城市和它的 IANA 时区。
  - 保存 IANA 名称。
  - 内置一份城市表（至少 300 个常用城市，中文名 + 时区），放在 `src/` 的数据文件里。
  - 可以作为 `list` 的子项使用，世界时钟靠它添加最多 10 个城市。
- **多行文本**：`text` 设置和状态页 `fields` 都新增 `multiline: true`。
  - 输入框随内容长高，最多 6 行。
  - 回车换行，Ctrl+Enter 提交。
- **list 子项的图标和颜色**：
  - 新增子项类型 `icon`：从宿主内置图标里选，至少提供爱心、蛋糕、戒指、飞机、星星、礼物、旗子、日历、咖啡、硬币、太阳、月亮。
  - 新增子项类型 `color`：从 8 个预设色里选。
  - 两种都保存为名字字符串。画布可以用 `{"icon":"heart","rect":[…]}` 节点画出同一套图标。
- **私有存储导出和导入**：在插件详情的「···」菜单加「导出数据」「导入数据」。
  - 导出的 JSON 包含插件 ID、dataVersion 和 storage。
  - 导入时核对插件 ID 和 dataVersion。
  - 便签本不限条数，靠这个做备份。

## 验收标准

- 单元测试覆盖：
  - 常驻画布的尺寸和节点上限；
  - 字体包的格式、大小、许可文件检查；
  - 字体回退；
  - 时区搜索中文匹配；
  - 多行文本的保存；
  - icon、color 子项的取值校验；
  - 导入时 ID 不符拒收。
- egui 测试：常驻小画布在两种皮肤、左右停靠和顶部停靠下都不越界。
- 演示：装一个开源中文字体包，演示插件的标题改用这个字体。
