## 已定的方向

- 作者用岛仔提供的组件描述界面，用少量主题令牌调样式，岛仔负责绘制。不做自由绘制，也不嵌网页。
- 需要每秒变化的内容（跳动的数字、时钟、倒计时）由岛仔在本地逐帧计算，不让脚本每秒运行一次。
- 不做发布者签名。插件照旧在插件仓审 PR，由小唐本人过目后发布。
- 不引入付费服务或付费证书。
- 各任务负责数据约定、校验、运行逻辑和测试。界面先用宿主现有控件画出能用的样子，最终的视觉设计由验收方统一来做。

## 共同规则

- 所有回复用中文。
- 本机 Cargo 命令一律通过 `spike/cargo-serial.ps1` 运行，它会持有互斥锁 `Local\Daozai.Cargo`，并行度为 1。
- 每个工作树只用自己目录下的 `target`，不设 `CARGO_TARGET_DIR`。新工作树第一次编译大约需要 12 分钟。
- 这些任务**只提交到自己的分支**：
  - 不合进 `test/acceptance` 或 `main`；
  - 不编译 release，不替换桌面「岛仔－当前测试版」；
  - 不推送到 GitHub。

  验收、合并和出包由验收方统一处理。
- 分支最后要合到一起，所以改动尽量放进新文件。下面这些共享位置只做增量修改：
  - 能力表 `CAPABILITIES`；
  - `spike/local.rs` 里的 `Output` 和 `render_input`；
  - `src/plugin_status.rs` 里的 `StatusComponent`；
  - 文档表格；
  - 教程能力清单（`spike/plugin_guide_ui.rs` 约 225 行）。
- 插件提供的设置和选项，要在所属设置页的标题旁显示「插件」小标。插件开关开启时为紫色、关闭时为灰色，复用宿主现有组件。
- 设置页里的说明和关键提醒不要删。状态提示用颜色和动效表达，不加文字标签。
- 文件多为 CRLF 换行，编辑时保持原样。
- 每个任务都要同步更新这三处：[sdk-v1-design.md](../sdk-v1-design.md)、[sdk-v1.schema.json](../sdk-v1.schema.json)、教程能力清单。新增的能力在文档里标为「实验」。
