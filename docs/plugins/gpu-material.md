# GPU 材质接口规范 v1

状态：**定稿**，对应插件清单 `api: 1`。本文件约定的清单字段、着色器接口、控件角色和宿主行为，在 `api: 1` 内只按「稳定性约定」一节追加，不改变已有含义。第 6 阶段把定稿时新增的几项落地后，随 `feat/gpu-material` 合进 `main`（合并前须完成文末的补测）。材质插件支持本地安装和[本地测试集市](local-install.md#测试集市)，正式分发另行规定。

实现分支 `feat/gpu-material`，工作树 `01-专项工程/GPU材质`。实现过程见 [gpu-material-tasks.md](gpu-material-tasks.md)。

## 目标

让插件给岛体换上实时 GPU 材质：岛体背后的桌面透过材质折射、模糊或变色，控件有独立的玻璃块和弹性。本体只提供通用能力，不含任何具体材质的算法和参数。材质作者只交一段 WGSL 着色器和一份参数清单。

第一个材质插件是液态玻璃（作者 轻九九九，@cayww，源自 PR #235），位于 `spike/examples/liquid-glass/`，是本规范的参考实现。

## 分工

| 宿主（岛仔本体）提供 | 材质插件提供 |
|---|---|
| 岛体背后的桌面底片、平均亮度、带滞回的明暗状态 | WGSL 着色器 |
| DirectComposition 透明交换链，真实逐像素 alpha | 参数清单：名称、范围、默认值、单位、显示精度 |
| 把着色器接进渲染通道，传入岛体轮廓、控件、指针、时间、展开速度 | 控件弹簧的刚度和阻尼 |
| 控件登记、角色编号、弹簧和按压动画 | 投影强度、前景样式的选择 |
| 岛体投影、玻璃前景样式（按钮、卡片、文字深浅） | 作者、版本、说明 |
| 着色器检查，出错和超预算时停用并退回普通绘制 | |
| 根据参数清单生成设置滑块 | |
| 静止降频、深休眠、抓屏节流 | |

## 运行条件

- 只在「兼容渲染（Direct3D 12）」开启时生效。启用材质插件时兼容渲染未开，提示开启并重启，期间插件处于等待状态，基础皮肤不变。
- 同一时间只有一个材质生效，启用新的会停用旧的。材质叠加在用户当前的基础皮肤和形状上；皮肤、形状、停靠仍由用户掌管。停用后外观回到原样。
- 只作用于主岛，设置窗口和其他窗口不受影响。
- 任何一步失败（建不起交换链、抓不到屏、着色器编译失败、连续超预算）都退回普通绘制并记入 `diagnostics/material.log`，直到用户重新启用，不影响岛仔其他功能。
- 材质生效期间，岛体窗口被排除出屏幕捕获，截图和录屏里看不到岛仔。设置中「截图和录屏隐藏岛仔」显示为开启并锁定，附说明；停用后按用户原来的选择恢复。两者共用宿主的 `capture::Exclusion`。

## 插件清单

```json
{
  "id": "cayww.liquid-glass",
  "name": "液态玻璃",
  "author": "轻九九九（@cayww）",
  "version": "1.0.2",
  "api": 1,
  "runtime": "material",
  "entry": "material.wgsl",
  "owner": "appearance",
  "capabilities": ["appearance.material", "settings"],
  "dataVersion": 1,
  "permissions": {"screen.backdrop": true},
  "material": {
    "controls": true,
    "spring": {"stiffness": 1.0, "damping": 0.5},
    "shadow": 1.0,
    "foreground": "glass"
  },
  "settings": [
    {"key": "refract", "label": "折射", "type": "number", "min": 0, "max": 120, "step": 1, "default": "48", "unit": "px", "precision": 0},
    {"key": "edge-opacity", "label": "白边不透明度", "type": "number", "min": 0, "max": 1, "step": 0.01, "default": "0.9", "precision": 2}
  ]
}
```

### 字段规则

| 字段 | 规则 |
|---|---|
| `runtime` | 固定为 `"material"` |
| `owner` | 固定为 `"appearance"` |
| `capabilities` | 必须含 `"appearance.material"`；有设置项时加 `"settings"`；不允许其他能力 |
| `entry` | 包内一个 `.wgsl` 文件，不超过 64 KB |
| `permissions` | 只能是 `{"screen.backdrop": true}` |
| `material.controls` | 是否需要控件玻璃数据，布尔 |
| `material.spring` | 必填。`stiffness` 0.2 至 3.0，`damping` 0.1 至 1.0，由宿主计算弹簧后传入着色器 |
| `material.shadow` | 可选，0 至 1.5。岛体外围投影强度，由宿主按岛体轮廓绘制。不写时沿用基础皮肤 |
| `material.foreground` | 可选，`"skin"`（默认）或 `"glass"`，见「前景样式」 |
| `settings` | 最多 32 项，只允许 `number` 类型，按声明顺序放进着色器的 `params` |
| `settings[].min/max/step` | 必填，`step` 大于 0 且不超过 `max - min`，`default` 在范围内 |
| `settings[].unit` | 可选，滑块数值后显示的单位，最多 4 个字符，例如 `"px"`、`"%"`。只用于显示，宿主不做换算 |
| `settings[].precision` | 可选，0 至 3，滑块显示的小数位数。不写时按 `step` 的小数位数显示 |

清单须声明 `"cover": "cover.png"`。包内只允许 `plugin.json`、包根目录的 `cover.png`、入口 `.wgsl` 和可选的说明文件（`.md`、`.txt`、`.rst`，或 README、LICENSE、COPYING、NOTICE、CHANGELOG）。封面须为有效 PNG，最大 256 KiB、1920×1080，建议 16:9。岛仔拒绝链接、重定向路径、脚本、可执行文件和未知清单字段。

### 权限

`screen.backdrop` 首次启用时确认，说明文字固定为：

> 读取岛体背后一小块屏幕画面，只在本机用于绘制材质，不保存、不上传；插件本身没有网络和文件权限。

实现上，宿主把裁剪后的像素读回岛仔进程内存，用于计算亮度和合成干净底片，再上传为显卡纹理。像素不写入磁盘和日志，插件只能在着色器里采样纹理。

### 前景样式

- `"skin"`：宿主照常画基础皮肤的底色、按钮和文字，材质画在底色之上、文字和按钮之下。
- `"glass"`：
  - 宿主不画基础皮肤的底色，岛体底色完全由材质负责；
  - 按钮、卡片改用宿主内置的玻璃样式；
  - 文字和图标随 `motion.y` 在深色字和浅色字之间切换；
  - 显示器拓扑刚变化、抓屏处于稳定期时，宿主临时画纯色玻璃底。

  启用后的外观不受基础皮肤影响。

## 着色器接口

宿主在插件代码前拼接固定的前置代码（prelude），提供输入结构、绑定和常用函数。插件只写片元函数：

```wgsl
fn material(i : MaterialIn) -> vec4<f32>
```

返回预乘 alpha 的颜色。顶点着色器由宿主提供，覆盖整个抓取矩形。插件不得声明其他绑定、`@vertex` 或 `@fragment` 入口，否则拒绝加载。

### 绘制顺序和边缘

宿主每帧按以下顺序绘制，材质输出按预乘 alpha 混合：

1. 岛体投影（宿主）；
2. 基础皮肤底色（宿主，仅 `foreground: "skin"`）；
3. 材质（插件）；
4. 按钮、卡片、文字、图标（宿主）。

抓取矩形比岛体大，用于折射取样。材质在 `body_sdf_exact(p) > 0` 的区域应输出透明，可以在轮廓外 2 px 内做抗锯齿过渡。宿主按窗口区域裁剪，不再替插件裁剪轮廓。

### Frame

```wgsl
struct Frame {
  capture : vec4<f32>,   // 抓取矩形在屏幕上的物理坐标 x,y,w,h
  body    : vec4<f32>,   // 岛体在抓取矩形内的 x,y,w,h（物理像素）
  shape   : vec4<f32>,   // 圆角半径 px、展开程度 0..1、指针 x、指针 y（抓取矩形内 px）
  notch   : vec4<f32>,   // 刘海外扩宽度 px、外扩高度 px、是否刘海、保留
  env     : vec4<f32>,   // 时间 s、背景平均亮度 0..1、物理像素/逻辑点、是否透明交换链
  tint    : vec4<f32>,   // 封面主色 rgb、强度
  tex     : vec4<f32>,   // 底片纹理宽、高、有效区宽、高
  count   : vec4<u32>,   // 控件数量、停靠方向（0 顶部、1 左侧、2 右侧、3 底部）、保留、保留
  ctl_rect  : array<vec4<f32>, 16>, // 控件 x,y,w,h（抓取矩形内 px）
  ctl_shape : array<vec4<f32>, 16>, // 圆角半径、启用、悬停 0..1、按下 0..1
  ctl_spring: array<vec4<f32>, 16>, // 弹簧位移 x、y、缩放、控件角色（见附录）
  params  : array<vec4<f32>, 8>,    // 插件参数，按清单 settings 顺序，每 4 个一组
  motion  : vec4<f32>,   // 展开速度、宿主明暗状态 0..1（0 深 1 浅）、平滑展开速度、保留
};
@group(0) @binding(0) var<uniform> frame : Frame;
@group(0) @binding(1) var backdrop : texture_2d<f32>;
@group(0) @binding(2) var backdrop_sampler : sampler;
```

- `Frame` 共 1040 字节，每项按 16 字节对齐。
- 标为「保留」的位置当前恒为 0，插件不得读取，以后追加的含义不保证为 0。
- `motion.x`：展开程度每秒的变化量，收起为负，逐帧求导。
- `motion.y`：宿主明暗状态，背景平均亮度高于 0.66 转浅、低于 0.52 转深，按每秒 6 倍平滑。与玻璃前景样式的文字深浅是同一个值。
- `motion.z`：`motion.x` 经过与 PR #235 相同的逐帧衰减后的值，用于展开收尾的形变回弹。
- 控件最多 16 块。超过时先保留附录中标为优先的角色，再按面积从大到小补足。入选的控件按面积从大到小排列，较小的控件排在后面。

### 前置函数

```wgsl
struct MaterialIn { px : vec2<f32>, uv : vec2<f32> };   // px 为抓取矩形内的物理像素坐标
fn param(i : u32) -> f32;                                 // 第 i 个插件参数
fn rr_sdf(p : vec2<f32>, b : vec2<f32>, r : f32) -> f32; // 圆角矩形距离，b 为半宽高
fn notch_sdf(p : vec2<f32>, b : vec2<f32>, r : f32, flare : f32, fh : f32) -> f32;
fn body_sdf(p : vec2<f32>) -> f32;        // 当前岛体轮廓，向内收缩 3 px，留给羽化和描边
fn body_sdf_exact(p : vec2<f32>) -> f32;  // 当前岛体轮廓，不收缩，与窗口可见边缘一致
fn sample_backdrop(px : vec2<f32>) -> vec3<f32>; // 按抓取矩形内像素坐标采样底片
```

两个轮廓函数都已处理刘海、展开程度和四个停靠方向。距离小于 0 在岛体内。

## 稳定性约定

- `api: 1` 内，`Frame` 已有字段的位置和含义、绑定编号、前置函数的签名和含义、控件角色编号、清单已有字段的含义都不再改变。
- 新增只能是：`Frame` 末尾追加字段、使用保留位、增加前置函数、追加控件角色编号、清单增加可选字段。新增内容随岛仔版本发布并在本文件记录起始版本。
- 插件声明的 `api` 大于宿主支持的版本时，拒绝安装并提示更新岛仔。
- 需要破坏性修改时升级为 `api: 2`，宿主同时保留 `api: 1` 的支持至少六个月。
- 插件 `version` 用三段语义化版本。从插件首次对外发布起，清单变化需要用户重新安装时至少升级第二段；发布前的本机验收版本不受此限，液态玻璃的 1.0.x 即属此类。

## 性能与稳定

- 静止时按 15 Hz 刷新，无操作 2 分钟进入 1 Hz 深休眠，动画和交互期间满帧。由宿主控制，插件不可修改。
- 抓屏只读外扩矩形，尺寸变化时不复用旧纹理。
- 着色器在宿主的错误范围内编译，失败即停用并提示。
- 材质通道连续 120 帧 CPU 耗时超过 4 ms 自动停用。
- 启用、停用、切换材质时释放纹理和管线，内存回到启用前水平。

| 文件 | 内容 |

| `src/material/prelude.wgsl` | 前置代码 |
| `spike/local.rs`、`spike/local_ui.rs` | 材质清单校验、安装、权限确认、启停、参数滑块 |

## 验收

- 关闭材质插件时，岛仔各皮肤的显示、内存、帧率与 `main` 一致，现有测试全部通过。
- 液态玻璃与 PR #235 预览版在同一壁纸、页面、参数下对比：折射、色散、白边、投影、玻璃按钮、文字深浅、控件透镜、果冻弹簧和展开形变一致。
- 关闭兼容渲染、着色器写错、抓屏失败时都退回普通绘制，岛仔不崩溃。
- 停用插件后外观回到启用前的皮肤和形状，截图排除恢复用户原设置。

### 合进 main 前的补测

以下三项针对会影响所有用户的改动（兼容渲染的建窗口流程、#197 截图排除的内部实现），未安装材质插件时也要测。全部通过后才合进 `main`，结果记在合并说明里。

1. **其他显卡的兼容渲染**：在 AMD 和 NVIDIA 显卡的机器上开启「兼容渲染（Direct3D 12）」，不装材质插件，检查各皮肤的展开、收起、切页和侧边停靠是否正常，与 `main` 的同款测试版对比无异常。
2. **截图排除开关**：不装材质插件时，「截图和录屏隐藏岛仔」分别开、关并重启，检查开关状态保存、系统截图里岛仔的显示与开关一致；装上材质插件后启用、停用各一次，确认开关被锁定和恢复原值。
3. **录屏软件实录**：用 OBS 等录屏软件的窗口捕获和显示器捕获各录一段，确认截图排除开启时录不到岛仔、关闭时能录到，材质生效期间录不到。
