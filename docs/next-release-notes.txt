- 插件集市上线，首批 8 款可在「设置 → 插件」安装。
- 新增系统性能和无线设备页，性能指标、网速和设备电量可在岛上常驻。
- 支持底部停靠、跨屏拖动，以及在兼容的截图和录屏工具中隐藏岛仔。

### 新增

- 首批插件包括液态玻璃、我的日子、现货金价、实时工资、便签本、世界时钟、页面快捷切换和无线设备兼容包。液态玻璃是轻九九九（@cayww）的社区插件。
- 日程新增按日期浏览、农历常驻和时间选择器。邮箱可只提醒验证码，Gmail 收信支持 Windows 手动代理。
- AI 额度加入 Antigravity，「关于」新增感谢墙。

### 优化

- 集市支持按下载量或最新更新排序、收藏和作者头像。独立功能插件启用后才出现在侧栏和岛上，更新时保留设置和数据。
- 兼容渲染下展开、收起和翻页更顺滑，切页时顶栏和箭头更稳定，置物架和剪贴板可保持展开。
- 切歌、暂停和拖进度同步更快，改善酷狗和网易云部分版本的进度适配。
- 自动更新提示集中在启动时，在线升级留出更充足的准备时间，诊断可直接生成 ZIP。

### 修复

- 修复部分钉钉、飞书提醒点不开或打开后仍保留，以及顶部任务栏挡住通知点击。
- 修复波点歌曲显示成编号，以及蓝牙设备切换电量来源后读数或提醒异常。
- 修复侧边控件裁切、兼容渲染首帧闪黑、毛玻璃开关失效，以及透明边缘挡住点击。
- 修复窄窗口的集市分类遮挡、岛上组件增减时偏移，以及喝水页切换图表卡顿。
- 修复 CalDAV 连上后无法保存、Kimi Code 重新登录后额度未恢复，以及中文输入法选词时误提交。

### 升级与下载

点「下载并安装」即可升级，设置和记录会保留。也可在「设置 → 关于」手动检查更新。首次安装选 EXE，免安装选 ZIP。
